# Contribute to Open Source

Before going live with our open sourced code, we are building out the initial iteration of the Kintsu protocol using private repositories.&#x20;

Please check this page again once Kintsu goes live as open source contributions will then be possible.&#x20;

In the meantime, if you would like to be a part of the selective few who are building the foundation of Kintsu before going live, please fill out the following form for our team to review. We look forward to hearing from you!
